# Branding Assets / 品牌资产

`AppIcon.png` is the original 1024×1024 transparent master artwork for
ReadyDownloader. It combines a film frame with a download arrow without
using any third-party platform logo or trademark.

`AppIcon.png` 是 ReadyDownloader 的原创 1024×1024 透明主图，将胶片框与
下载箭头组合在一起，不使用任何第三方平台的 Logo 或商标。

The artwork is distributed under the repository's MIT license. Run
`./script/generate_macos_icon.sh` to generate the `.icns` used by macOS builds.

该图形随仓库使用 MIT 许可证发布。执行 `./script/generate_macos_icon.sh` 可生成
macOS 构建使用的 `.icns`。
