# ReadyDownloader 0.2.1

`0.2.1` 使用与 ReadySuite 相同的 Vercel 方案，为生产 Web 应用加入隐私安全的产品统计。

## 已交付

- 第一方 Web Analytics 页面访问统计
- 覆盖解析、下载、语言切换、保存文件和 GitHub 跳转的产品漏斗埋点；面板采集需要 Vercel Pro 或 Enterprise
- Speed Insights 接入代码；Vercel 团队有可用项目名额后即可开始采集
- 明确的事件字段白名单和自动化载荷测试
