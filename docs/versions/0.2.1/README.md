# ReadyDownloader 0.2.1

Version `0.2.1` adds privacy-safe product analytics to the production Web app using the same Vercel integration as ReadySuite.

## Delivered

- First-party Web Analytics page views
- Product funnel instrumentation for analysis, download, language switching, file saving, and GitHub navigation; dashboard collection requires Vercel Pro or Enterprise
- Speed Insights instrumentation, ready for collection when the Vercel team has an available project slot
- An explicit event-field allowlist and automated payload tests
