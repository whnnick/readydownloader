# YouTubeDlpDownloader 0.1.2

`0.1.2` 修复 macOS APP 在不完整构建中找不到运行组件的问题，并加入完整的简体中文 / English 即时切换。

## 版本目标

- 主窗口、设置、菜单、格式表、状态和错误提示均支持中英切换。
- 语言偏好持久保存，切换时保留当前链接、解析结果和下载状态。
- 正式发布包优先使用内嵌工具；SwiftPM 开发构建能够回退到仓库的固定工具目录。
- 缺少工具时明确提示使用当前 DMG/ZIP 中的 APP，而不是笼统要求重新安装。
