# YouTubeDlpDownloader 0.1.1

Version `0.1.1` focuses on the Chinese macOS interface and core download interaction. Windows remains a compatibility prototype.

## Goals

- Align with ReadyType's macOS visual language: adaptive neutrals, moss-green accents, panel hierarchy, restrained radii, and plain Chinese copy.
- Guide the user through paste, query, download-mode selection, and download in a predictable order.
- Provide actionable feedback during queries, downloads, cancellation, success, and failure.
- Preserve the yt-dlp, unrestricted best-quality, and FFmpeg merge behavior verified for `0.1.0`.
