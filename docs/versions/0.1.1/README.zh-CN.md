# ReadyDownloader 0.1.1

`0.1.1` 聚焦 macOS 中文界面与核心下载交互，Windows 仍作为兼容原型维护。

## 版本目标

- 与 ReadyType 的 macOS 视觉语言保持一致，包括自适应灰阶、苔绿色主色、卡片层级、圆角和中文文案语气。
- 让用户按“粘贴链接、解析、选择下载方式、下载”的顺序完成任务。
- 在解析、下载、取消、成功和失败期间提供明确、可操作的状态反馈。
- 保持 `0.1.0` 已验证的 yt-dlp、最高画质和 FFmpeg 合并行为不变。
