# YouTubeDlpDownloader 0.1.0

`0.1.0` 是计划中的首个公开双平台版本。

## 版本目标

提供一个可信的 yt-dlp 原生桌面界面，支持：

- Windows 10+ x64；
- macOS 14+ Apple Silicon。

两个客户端必须实现相同的核心流程：查询单个媒体链接、查看视频格式、选择输出、显示下载进度、必要时合并音频，并能定位完成的文件。
