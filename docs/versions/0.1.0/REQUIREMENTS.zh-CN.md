# 0.1.0 产品需求

## 产品边界

`0.1.0` 是单任务桌面下载器，不是媒体库、浏览器、爬虫、账号管理器或 DRM 绕过工具。

## 支持平台

- Windows 10 或更高版本，x64。
- macOS 14 或更高版本，Apple Silicon。

Intel Mac、Linux、移动平台和应用商店分发不在本版本范围内。

## 功能需求

### 链接和元数据

- 接收一个用户提供的链接。
- 启动 yt-dlp 前拒绝空链接。
- 使用 yt-dlp JSON 输出查询元数据，不解析面向用户的文本表格。
- 单任务流程不处理播放列表。

### 格式列表

- 在数据可用时显示格式 ID、封装、分辨率、宽度、高度、帧率、视频编码、音频编码、预估大小和码率。
- 排除纯音频、故事板、没有有效视频编码或高度的条目。
- 格式列表加载后保持明确、稳定的选择状态。

### 下载

- 下载用户选择的视频格式。
- 仅当选中格式没有音频流时追加最佳音频。
- 必要时使用 FFmpeg 合并音视频。
- 允许用户选择可写的保存目录。
- yt-dlp 提供数据时显示进度、速度和剩余时间。
- 允许取消正在执行的查询或下载。
- 下载完成后可以在资源管理器或 Finder 中显示文件。

### 工具链

- 在操作前检查所需的 yt-dlp、FFmpeg、ffprobe 和 Deno。
- 发布打包期间不使用未经校验的下载文件。
- 在发布清单中记录工具版本和校验值，不把工具二进制提交到 Git。
- 工具缺失、架构不兼容或无法启动时显示可操作的错误。

### 网络和登录

- 支持直连、系统代理和用户填写的自定义代理。
- 新用户默认不启用 localhost 代理。
- 浏览器导出的 Cookie 是可选的用户私密数据。
- 不能仅因为缺少 Cookie 就阻止下载公开内容。
- 日志不得输出 Cookie 内容或 Authorization 请求头。

### 诊断

- 提供简洁状态信息和可选的详细日志。
- 原始工具错误只出现在详细日志中。
- 对常见登录、网络、JavaScript 运行时、FFmpeg、格式和链接错误提供可操作提示。

## 非功能需求

- 每个平台使用原生桌面 UI。
- 在可分发应用中内嵌一致的原创项目图标。
- 查询和下载期间界面保持响应。
- 后台任务具有明确的生命周期和取消机制。
- 多字节 UTF-8 字符跨越管道读取边界时不能损坏。
- 两个平台的用户行为和发布版本保持一致。
- 源码和公开包中不得包含 Cookie、下载媒体、凭据、私人路径、IDE 状态或调试符号。

## 不在范围内

- 播放列表和频道下载。
- 并发下载队列。
- 下载历史或媒体管理。
- 应用自动更新。
- 从浏览器自动提取 Cookie。
- DRM 绕过。
- Intel Mac 稳定支持。
