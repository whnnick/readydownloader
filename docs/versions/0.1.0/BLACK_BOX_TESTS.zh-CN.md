## 必需真实环境验证

- 两个平台使用已获授权的公开视频完成下载。
- 两个平台完成纯视频与音频合并。
- 两个平台取消一个部分下载任务。
- Finder 和资源管理器定位文件。
- 普通用户机器上的直连和系统代理行为。
- 干净 Windows 账号和干净 macOS 账号首次启动。
- 对已签名、公证的 macOS 产物执行 Gatekeeper 检查。

## 发布包黑名单

发布包不得包含：

- Cookie 文件；
- 已下载媒体或 `.part` 文件；
- `.env` 或凭据；
- PDB、OBJ、IPCH、TLOG 或 IDE 数据库；
- 开发者绝对路径；
- `.codex`、`.agents`、`AGENTS.md` 或仅供内部使用的检查清单；
- 其他版本遗留的旧产物。
